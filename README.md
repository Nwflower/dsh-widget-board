# dsh-widget-board

[English](README.en.md)

DeepSeek Harness 的组件看板插件。侧栏多一个「看板」入口，中栏是一页可以拖动、缩放、展开的卡片看板，每张卡片是一个小组件：天气、统计数字、任务列表、图表，或者你让 agent 现写的任何东西。

- **让 agent 写组件**：在会话里描述想要的组件，agent 编写、检查各个尺寸下的显示效果、放上看板。
- **在会话里直接显示**：agent 可以把组件内联显示在回答里，数据更新时卡片随之变化。
- **适应各种屏幕**：看板按自身宽度切换列数，每个组件按声明的尺寸族排版，窄屏、宽屏、右侧栏里都能正常显示。
- **分享与导入**：组件与整块看板都能导出成一个文件，或从链接、git 仓库导入；导入时显示它需要的权限，由你批准。
- **安全隔离**：每个组件运行在独立的沙箱里，拿不到你的会话、文件与网络，需要执行命令或访问网络时先问你。
